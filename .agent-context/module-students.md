# Módulo: Listado de Alumnos

- **Estado actual**: UI funcional y terminada visualmente, operando como Demo.
- **Dependencias actuales**: Consume de `mockData.ts`.
- **Datos mínimos requeridos**:
  - ID, Nombre completo, Matrícula, Grupo, Estado (activo/inactivo), y métricas resumidas (número de incidentes).
- **Criterios de Aceptación**:
  - Tabla de alumnos mapeada con registros de la base de datos (Supabase).
  - Navegación fluida al `StudentRecord` pasando el ID correcto.
